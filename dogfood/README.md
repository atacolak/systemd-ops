# Dogfood

systemd-ops is the substrate: responsibility scopes, timers, observation,
and the operator cockpit.

The OMP graph is one application built with that substrate. Its live
scope is `/home/sf/workspace/oh-my-pi`. Scripts in this directory are
the tracked copy of that application's wrappers.

`topology.txt` is authored by the scope lead. It explains intended
recurrent work to a human. It is not systemd truth, not graph
readiness, and not an automation membership list.
